К вопросу

Локально

RuDataAnalyst-SQL

Вопрос на русском, SQL, ограничения сервера и показанная выборка. Данные вкладки никуда не отправляются.

Состояние API ещё не проверено.

/health сообщает только доступность API и флаг model_loaded.

Запрос

Ctrl+Enter или ⌘+Enter отправляет режим «Сгенерировать и выполнить». Остальные сочетания перечислены ниже.

Примеры

В этой вкладке

Отправленные вопросы и их ответы остаются здесь до закрытия вкладки. Повторной генерации при выборе нет.

«Только SQL» ничего не запускает. «Сгенерировать и выполнить» заново получает SQL из вопроса, а не из текста на экране.

Клавиши

Кнопка прерывает только ожидание в браузере. Она не обещает остановить уже начатую генерацию на сервере.

Вопросы и результаты остаются в памяти вкладки, пока вы её не закроете. Автосохранения и внешней аналитики нет.
